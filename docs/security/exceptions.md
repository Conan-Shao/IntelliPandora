# 漏洞例外登记

> 只有在**某个已知漏洞还没有修复版本**，或者经评估确认不影响本框架时，才在这里登记例外。例外必须写明理由和到期日。
>
> CI 会读取这张表（`scripts/check_components.py`）：
> - 未过期的例外，会作为 `--ignore-vuln` 传给 pip-audit；
> - **已过期的例外会让 CI 失败**。这样例外就不会悄悄变成永久豁免。
>
> 到期后需要重新评估：要么升级掉，要么续期，续期要重新写理由。
